# Publication Scope and Checklist

This independent copy contains reusable scBeacon, its skill/tutorial and three
dataset analyses. Benchmark upstream code, abandoned searches, private chat
evidence and Illustrator working archives are excluded. Original analyses and
github_ready_folder are not modified.

Before making this repository public:

- Confirm authorship, upstream permissions and the license for the unifan-named
  shared implementation. No license is invented in this candidate.
- Choose a prepared-data archive, approve redistribution under source dataset
  terms and assign persistent download URLs. Large inputs are local-only until
  that decision; no archive URL is fabricated.
- Review patient/sample metadata and public-study barcodes for intended release.
- Review validation_report.json and the notebook environment record. Cached
  execution does not certify fresh GPU training.
- Add final software version/citation/archive DOI when actually available.

Private repository upload is a packaging operation only. It does not rerun
analyses, modify original analysis directories or globally install the skill.
